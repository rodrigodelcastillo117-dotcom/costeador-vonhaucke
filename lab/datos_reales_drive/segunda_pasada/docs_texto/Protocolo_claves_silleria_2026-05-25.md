### Resumen

Revisión de procesos de importación y control de inventario mediante nueva gestión de rechazos y digitalización.  
  
**Detección de problemas operativos**  
Las variaciones en las especificaciones de sillas importadas causan inconsistencias en el inventario. El equipo identifica la falta de un protocolo formal para gestionar discrepancias en la recepción.  
  
**Protocolo de rechazo definido**  
El grupo acuerda utilizar el rechazo de compra como disparador oficial para evaluar discrepancias. Se establece el uso de una clave raíz única para garantizar la trazabilidad.  
  
**Mejoras en recepción visual**  
Se integrarán fotografías en los documentos de compra y en el control de importaciones para validar productos. El archivo de gestión base facilitará la estandarización de datos técnicos.
